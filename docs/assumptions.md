# Assumptions & decisions

Plan rule 7: document assumptions. Add an entry per stage as decisions are made.

| Date | Stage | Assumption / decision | Why |
|------|-------|-----------------------|-----|
| 2026-09-14 | scaffold | Neuron model v1 = Leaky Integrate-and-Fire (no Hodgkin-Huxley). | Plan §2.3. |
| 2026-09-14 | scaffold | Connectome topology is fixed; only synaptic weights are trainable. | Plan §16. |
| 2026-09-14 | scaffold | No large ML model between environment and brain; adapters are simple transforms. | Plan §2.1. |
| 2026-09-14 | scaffold | CPU-only, NumPy. No GPU/Rust until the hypothesis works. | Plan §42. |
| 2026-09-14 | scaffold | ViZDoom/Gymnasium are not dependencies yet; added at stage 18. | Plan §44. |
| 2026-09-14 | 0 | Synchronous update: a step reads activities from the previous tick, so a signal travels one synapse per tick and neuron order is irrelevant. | Determinism; matches Plan §40 replay requirement. |
| 2026-09-14 | 0 | Activity is binary (0/1) and potential resets to 0 on firing. Leak is applied before input: `p = p*(1-decay) + I`. | Simplest model that satisfies Plan §6 acceptance criteria. |
| 2026-09-14 | 0 | Pure Python dicts, no NumPy in the brain yet. | 3 neurons; vectorise only when the 302-neuron connectome demands it (Plan §42). |
| 2026-09-14 | 1 | World is a bounded box; walls are sensed and collide like obstacles. Obstacles are circles. | Simplest geometry with exact ray casts. |
| 2026-09-14 | 1 | Sensor reading = `1 - distance/range` clamped to [0,1]; rays at +45°, 0°, -45° from heading, range 4.0. | Proximity, not distance, so "closer" is "stronger" (Plan §8 uses the same convention for food). |
| 2026-09-14 | 1 | On collision the agent keeps its rotation but does not move; collision is counted. | Avoids tunnelling and gives a clean signal for later reward (Plan §9). |
| 2026-09-14 | 1 | Adapters are introduced now: `SensoryAdapter` (channel -> neuron, gain, tonic currents) and `MotorAdapter` (two neuron ids -> wheels). | Plan §2.2 wants independent layers from the start; both are tiny. |
| 2026-09-14 | 1 | Motor neurons run on a tonic current of 1.0 and sensors inhibit the *opposite* wheel. Front also excites the left wheel so a front+right conflict still turns right instead of freezing. | Hand tuning only (Plan §7); first wiring deadlocked and was fixed. |
| 2026-09-14 | 2 | Food is a gradient sense, not line-of-sight: signal = `1/distance` clamped to [0,1], routed to one of three sectors (front ±30°, left, right) by bearing. Food behind is still sensed on a side. | Plan §8 formula; chemosensation in the worm is not directional vision. |
| 2026-09-14 | 2 | Only the *nearest* food item is sensed, so the three food channels are mutually exclusive. | Binary neurons cannot compare magnitudes; two foods on opposite sides deadlocked the hand-wired brain. |
| 2026-09-14 | 2 | Hunger grows `hunger_rate` per tick, saturates at 1.0 (`World.starved`), resets to 0 on eating. Food is consumed on contact. Starvation has no consequence yet. | Consequence is a reward matter (stage 3). |
| 2026-09-14 | 2 | Hunger is exposed as an observation channel and gates food attraction in the demo through a HUNGRY interneuron. | Shows motivation observably: a sated agent drives past food. |
| 2026-09-14 | 2 | Shared `experiments/episode.py` holds the closed loop, trace record and rendering; stage demos only build scenarios. | Avoids copy-paste between stage demos. |
| 2026-09-14 | 3 | Reward lives in `learning/reward.py` as `RewardConfig` + `RewardTracker`; it takes plain event flags (ate, collided, starved) and position, not the World, so any environment can feed it. | Plan §9 single source of numbers; keeps learning decoupled from simple_2d. |
| 2026-09-14 | 3 | Exploration bonus counts distinct `floor(x/cell)`, `floor(y/cell)` cells with cell 1.0; collision penalty per tick, capped at 20 per episode; starvation scored once and ends the episode. | Plan §8-9 as revised. |
| 2026-09-14 | 3 | Episode ends inside `run_episode` on `world.starved` or after `steps`. Demo `hunger_rate` moved from 0.01 to 0.004 (starves in 250 ticks). | Plan §8 range 0.002-0.005; the stage-2 demo still eats both items and then starves, since respawn is stage 4. |
| 2026-09-14 | 4 | Genome = weight vector of the stage-2 topology (12 synapses) in insertion order; thresholds, decay and adapter wiring (tonic 1.0 on motors) stay fixed. Initial weights uniform in [-1, 1], mutation Gaussian σ=0.3, clipped to [-2, 2], truncation selection with 20% elites, no crossover. | Plan §10 algorithm literally; simplest thing that shows learning works. |
| 2026-09-14 | 4 | Fitness = mean total reward over 4 fixed train seeds (random start pose, 2 food items with seeded respawn, fixed obstacle). Held-out seeds 1000+ report generalisation. | Plan §10 revised: never one map. Obstacle layout stays fixed until stage 12. |
| 2026-09-14 | 4 | The closed loop moved from `experiments/episode.py` to `doomworm/episode.py` and scores ticks through a `TickScorer` protocol, so `learning` can import the loop without a cycle. | Layering: episode < learning < experiments. |
| 2026-09-14 | 4 | Brain JSON format v1: neurons (id, threshold, decay), synapses (source, target, weight, kind), meta (scenario, seeds, fitness...). `doomworm play` rebuilds adapters from `meta.scenario`. | Plan §40. Adapters are scenario code, not data, for now. |
| 2026-09-14 | 4 | Known failure mode of the evolved brain: on some seeds (e.g. 1000) it freezes when obstacle-right and food-right fire together and both motors are inhibited. | Binary neurons; addressed by graded activity from stage 5 (Plan §2.3), not by tweaking this stage. |
| 2026-09-14 | 5 | Dataset: Cook et al. 2019 hermaphrodite tables (SI 5 corrected July 2020, SI 4 cell lists) from wormwiring.org, extracted to CSV by `scripts/fetch_connectome.py`. No explicit license on the site; used as published SI for research, cited in `data/connectome/cook2019/README.md`. | Plan §11. |
| 2026-09-14 | 5 | 302 neurons = 83 sensory + 91 interneurons + 126 motor + CANL/CANR (type `neuron`, unclassified). Muscles, glia and end organs dropped. Dataset "weight" is EM serial sections of connectivity, not a synapse count. 38 chemical self-loops and 14 gap-junction self entries kept as in the source. | Keep the data as published; interpretation lives in `build_network`. |
| 2026-09-14 | 5 | Gap junction pair (a, b) becomes two positive electrical synapses a->b and b->a. Chemical sign: negative iff the source is one of the 26 classic GABA neurons (DD, VD, RME, RIS, AVL, DVB), else positive. Training may flip signs later. | Plan §11 revised. GABA-uptake-only neurons (Gendrel 2016) are not treated as inhibitory. |
| 2026-09-14 | 5 | Weight normalisation: per target, `w = sign * gain * weight / sum(abs incoming weights)`, so every neuron's absolute incoming weights sum to `gain` (default 1.0). | Bounded input per tick regardless of hub size; hubs and leaves get equal drive, which is a simplification to revisit at stage 6. |
| 2026-09-14 | 5 | Graded neuron mode added (`Neuron.graded`): `activity = clip(potential / threshold, 0, 1)`, no reset. Binary mode stays default for stages 0-4 code; connectome networks are graded. Brain JSON writes `graded` per neuron, format version unchanged (field optional, default false). | Plan §2.3 revised. |
| 2026-09-14 | 6 | Network stability: with graded neurons the per-hop steady-state gain is `gain/decay`. Measured: gain ≥ 1.0 (decay 0.5) drives all 302 neurons to an all-on state that never switches off; gain 0.5 barely reaches AVA. Defaults set to `gain=0.45, decay=0.5` (0.9 per hop): a stimulus spreads to ~250 neurons and fades to silence within ~70 ticks after it stops. | Almost all synapses are excitatory (only 26 GABA sources); recurrent excitation with gain ≥ 1 is a fixed point. Training will move weights, so this is an initialisation choice, not a law. |
| 2026-09-14 | 6 | Per-target normalisation dilutes strong inputs into hubs: ASHL→AVAL is 15 of AVAL's 894 incoming sections, so AVA responds weakly (peak ~0.04) while low-input targets of ASH (ASK, ADL, AIA) respond strongly (~0.2). Propagation is read as ranking and timing, not absolute level. | Known artefact; alternative normalisations tried (global scale with cap) were unstable. Revisit at stage 8 when motor readout needs AVA/AVB levels. |
| 2026-09-14 | 6 | `stimulate()` resets the network, holds the stimulus for N ticks, then runs M silent ticks. The propagation tree lists direct targets that activated strictly after their parent, ranked by peak. | Simplest observable of Plan §12. |
| 2026-09-14 | 6 | Debug screen (§41) is rendered offline from a trace recorded with `record_activity=True`: environment panel, bar chart of the top-N neurons by peak activity, text with sensors/motors/reward. GIF via matplotlib PillowWriter. Record now also snapshots food positions per tick. | Plan §41 revised: PNG/GIF, no live window. |
| 2026-09-14 | 7 | Sensory mapping lives in `connectome/mappings.py` as an explicit route list (`channel -> neuron, gain`) with JSON save/load; the Plan §13 table is `default_sensory_mapping()`. `SensoryAdapter` now accepts one channel driving many neurons. | Plan §13: explicit, configurable, documented. |
| 2026-09-14 | 7 | Obstacle left/right -> ALM + FLP of that side; front -> AVM + both FLP. Food left/right -> AWA, AWC, ASE of that side; front -> all six. Hunger -> NSM + ASI (positive gain, as the plan says). Danger channels -> ASH, unused until stage 14. | Left/right onto L/R pairs is an admitted artifice (worm steers by dorsal/ventral head bends). NSM/ASI biologically signal food presence, so a "satiety = 1 - hunger" variant may work better; the adapter can express it (tonic +1, gain -1) if stage 9 needs it. |
| 2026-09-14 | 7 | Sanity circuits confirmed in the loaded network: front touch (AVM/FLP) reaches AVA and AVD within 3 ticks; food smell (AWC) reaches AIY on the next tick. | Real touch-escape and chemotaxis pathways survive the normalisation. |
| 2026-09-14 | 8 | `MotorMapping` groups (Plan §14): forward = AVB, PVC, VB01-11, DB01-07; reversal = AVA, AVD, VA01-12, DA01-09; turn_left = SMDDL, SMDDR, RIVL; turn_right = SMDVL, SMDVR, RIVR. JSON save/load like the sensory mapping. | Dorsal read as left, ventral as right: admitted artifice, the worm bends dorso-ventrally. |
| 2026-09-14 | 8 | `GroupMotorAdapter`: drive = gain·(mean forward − mean reversal), turn = gain·(mean turn_right − mean turn_left), wheels = clip(drive ± turn) in [-1, 1]. Default gains 10 because untrained activity sits at 0.01–0.1. | Continuous wheels per Plan §14; negative drive is reversal. |
| 2026-09-14 | 8 | The world now accepts wheel commands in [-1, 1]; negative = backwards. Stage 1-4 binary brains are unaffected. | Reversal is the worm's main escape behaviour; a 2D car can drive backwards. |
| 2026-09-14 | 8 | `run_episode(brain_steps=K)` runs K brain ticks per environment step with the same input and hands the motor adapter the mean activity over the window (Plan §3.1). Default stays 1 for stages 0-4. | Averaging in the loop keeps adapters stateless. |
| 2026-09-14 | 8 | Untrained connectome: front touch gives reversal > forward (wheels ≈ −0.2), food drives SMD/RIV symmetrically, so there is no steering until weights are trained (stage 10). | Expected: SMD asymmetry is dorso-ventral, not left-right. |
| 2026-09-14 | 9 | `WormScenario`: connectome network (gain 0.45, decay 0.5) + default sensory/motor mappings, 5 brain ticks per env step, group motor gains 6. Hand-set inputs: tonic 0.1 on AVBL/AVBR and obstacle channel gain 3. World as in stage 4. Saved as brain JSON with `meta.scenario = "worm"` and `meta.params`; `doomworm play` rebuilds it. | Tonic AVB drive is biologically grounded (AVB are tonically active forward command neurons); without it activity is zero and the agent never moves. |
| 2026-09-14 | 9 | Result of the untrained worm (Plan §15 "does meaningful behaviour appear"): it drives forward (drive ≈ +0.33), front touch cuts drive to ≈ +0.19 and raises the reversal group tenfold, but the sign never flips because excitation also spreads into the forward group; food moves the SMD/RIV turn signal by ±0.005 only. So: sign-correct touch response, no reversal, no steering, many wall contacts. | The dataset carries no AVA/AVB mutual inhibition and no left/right steering asymmetry; both must come from trained weights (stage 10). Sensory gain has no effect beyond 1 because graded sensory neurons saturate at 1.0. |
| 2026-09-14 | 9 | Log format: JSONL per tick (`save_log`) with pose, sensors, hunger, wheels, reward, events and the top-N active neurons; plus PNG trajectory and debug GIF. | Plan §15 logging list. |
| 2026-09-14 | 10 | `Simulator` is now a NumPy matrix step (`weights[target, source] @ activity`) with identical semantics to the per-neuron `Neuron.integrate/update`; state is written back to the neuron objects every tick. Verified against a plain-Python reference on random mixed graded/binary networks. 5x faster (0.17 s per 300-step worm episode). | Plan §42 forbids GPU/Rust, not NumPy; stage-10 training was 44 min per modest run without it. |
| 2026-09-14 | 10 | Connectome training starts from the dataset weights: generation 0 = the stage-5 genome plus Gaussian perturbations (`seeded_population`), not uniform random genomes. Mutation sigma 0.02 absolute (weights: median 0.012, max 0.34), clipped to [-1, 1]; signs may flip (Plan §11). | Training in place keeps the biological initialisation meaningful; uniform random weights would erase the connectome. |
| 2026-09-14 | 10 | Per-generation metrics (best, mean) are written to a CSV next to the brain JSON (Plan §39). | Reproducible experiment records. |
| 2026-09-15 | 10 | First connectome training run (pop 40, 25 generations, 3 train seeds, 400 steps, sigma 0.02, ~10 min): best train fitness −18 → +56 (untrained −32). Held-out seeds 1000–1004: 0, 2, 4, 4, 4 food, zero collisions, vs untrained 0 food and 3–239 collisions. Strategy: forward drive with a right-biased curvature (mean wheels ≈ 0.8 / 0.6) that sweeps the map and bends toward food; reversal is essentially unused (0–2 ticks). | Plan §10 acceptance ("moves toward food, collides less") holds for the connectome with only weights trained. Whether this beats a random topology is stage 11. |
| 2026-09-15 | 11 | Control topologies (`connectome/variants.py`): random = same neurons and connection counts, uniform endpoints, permuted weights, same number of gap-junction self entries; shuffled = degree-preserving edge swaps (in/out degree per neuron for chemical, degree for electrical, 10 rounds x edges), permuted weights, data self-loops kept; dense = all 302x302 ordered pairs as chemical connections, the real count non-zero. | Plan §17 A/B/C. Dense with a 5% mutation mask is the Free mode of §38/§49: topology emerges from which weights become non-zero, same simulator and training. |
| 2026-09-15 | 11 | Every variant uses the same sensory/motor mappings (named neurons), tonic AVB, normalisation, world seeds and evolution budget; only the wiring differs. | Plan §49 "same neuron count, similar connection budget, same environment, same training budget". |
| 2026-09-15 | 11 | Comparison result and §17.1 decision are in `docs/comparison.md`: Real ~= Random on held-out fitness (29 vs 27), Real fastest sparse learner and the only collision-free variant, Shuffled and Free eat more. One run per variant; ordering not statistically established. Worm stays primary, controls become mandatory in later training runs. | Plan §17.1. |
| 2026-09-15 | 12 | Random maps (`environments/maze/generator.py`): 5 circular obstacles with radius 0.8-2.0, margin 1.0 from walls and each other, random clear start pose, 2 respawning food, all from one seed. `WormScenario(maps="random")`; `doomworm play --maps` overrides the brain's setting. | Plan §18: random start, food, obstacles. Circles only; rooms and doors are stage 15. |
| 2026-09-15 | 12 | Training from the dataset weights directly on random maps stalled (best −1.85 from generation 5 to 24, held-out food 1). The stage-10 brain trained on the fixed map generalises partly to random maps (7 food on 6 unseen maps, 2 maps with positive reward). Curriculum fixes it: continue evolution from the stage-10 brain (`--init-brain`). | Harder maps need a starting point; one evolution seed each, so this is an observation, not a law. |
| 2026-09-15 | 13 | Target ("come to X"): a `Target` in the world with the same 1/distance sector sensing as food, reached on contact, respawning from the world seed, reward +10 (`RewardConfig.target`). `WormScenario(task="target")` removes food and adds one target; hunger keeps ticking as time pressure. | Plan §19 revised. |
| 2026-09-15 | 13 | The default sensory mapping routes `target_*` to exactly the neurons of `food_*` (AWA, AWC, ASE per side), so a brain trained on food follows targets without retraining: the worm cannot tell the two apart. | Plan §19: "target becomes the new attractive signal". Making them distinguishable is a later, deliberate step. |
| 2026-09-15 | 14 | `Danger` zone (Plan §20): a circle sensed like food/target (1/distance sectors -> `danger_*` -> ASH), not solid; every tick inside costs `damage_rate` (0.25) health, health 0 is death and ends the episode. Reward: damage −2 per tick, death −20 once (separate from starvation). For the robot this is a stairwell or a forbidden zone. | ENEMY of the Doom track is the same object under another name. |
| 2026-09-15 | 14 | Danger zones are placed clear of obstacles, agent and target; `WormScenario(dangers=N)`; stage-14 task = target + 1 danger on random maps, trained by curriculum from the random-map brain. | One new complexity on top of stage 13. |
| 2026-09-15 | 12-13 | Evaluation on six unseen random maps (`docs/results/stage12_13_eval_2026-09-15.md`): the random-map brain eats ~1 food per map with zero collisions; the fixed-map brain eats slightly more but collides. Targets transfer without retraining (3 of 6 maps for the stage-10 brain) because they drive the same neurons as food; the target task is harder than food because a single target does not reset hunger, so every episode is capped at 250 ticks. | Plan §18 acceptance met weakly; §19 transfer shown. Both effects are one-seed observations. |
| 2026-09-15 | 14 | Result: curriculum from the stage-12 brain on target + 1 danger gives zero damage and zero deaths on six unseen maps (baseline: 14 damage ticks, 3 deaths) but 208 collisions and only 2 targets. Reward −21 for both. | Avoidance is cheap for the network (ASH -> AVA reversal exists); approach is hard because a single target is a weak gradient and there is no food to reset hunger. Consider a longer episode cap or a target-reached hunger reset for the robot's "call" task. |
